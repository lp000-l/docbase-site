第 一 卷 · 功 能

三事俱备，治学开发皆宜

归文、行码、连库——把日常零散的操作收进同一处案头。

NO. 01

典籍归类，一览无遗

籍、码、图、数，无论何种文契，皆可于同一界面开卷浏览、就地编辑。五十余种格式自动识认，无需另装他器；任开一卷皆可按 Ctrl+F 通篇查找，命中处尽数点亮、逐处跳到眼前。

解释器随选，落笔即行

内置 Python、Node、C/C++、Go、Rust、Java 等二十余种解释器与编译器，选中即跑。运行出错一律译成中文：指出第几行第几列、什么毛病、该怎么改，原始英文报错退到折叠里备查。

越洋连库，直取数册

内嵌终端可经 SSH 远连服务器，亦可直通 MySQL / MariaDB、PostgreSQL、SQL Server、SQLite 库房，查改导一处完成。库房报错同样译成中文，并在 SQL 里标出出错的位置——表名拼错、列不存在、约束冲突，一眼看清。

编目标签，寻之即得

以钤印标签、卷册、最近入档为纲，纵有千册亦可顷刻寻见。检索直通文书正文与批注——记得住一句话、却忘了它在哪一卷，也翻得出来。

多卷并陈，各得其位

同时开卷多部，拖拽以调版式；可分屏对读、并行校订。数据库工作台还能把一份文书摊在左侧并读——写作业时不必在窗口之间来回翻找。

浏览器提示「可能有风险」，要不要担心？

这是正常的，不是文件被污染。Chrome / Edge 与 Windows SmartScreen 对「没有代码签名证书 + 下载量还少」的可执行文件一律会提示「可能有风险 / 不常下载，可能不安全」。文渊阁是个人开源软件，没有买代码签名证书，所以拿不到这个「签名」背书 —— 提示的是身份未被验证，不是查出病毒。

可以这样自行确认：把下载到的文件算一下 SHA-256，与下面那张表比对，一致就是官方原版；也可以装好后在软件里打开 设置 → 关于，程序会自查关键文件并列出一组校验码 —— 表里的构建编号与指纹和软件内显示的完全一致。两者都对得上，就可以放心。

想让它彻底不提示，只能买 OV / EV 代码签名证书并接进打包流程 —— 那要花钱（EV 每年数千元，OV 便宜些但还得靠下载量慢慢积累信誉）。目前先用「公开校验码 + 程序内自查」这套替代办法。

下载很慢、中途断了怎么办？

慢在哪：官网这台服务器在境外（欧洲节点），从国内跨境过去要绕远路 —— 链路往返约 300 ms、丢包约一成。丢包会让单条连接被反复打断，速度自然上不去。

已经做了两件事：
· 服务端换了拥塞控制算法（BBR）并调大 TCP 缓冲：BBR 对丢包不敏感，实测单连接从 12 KB/s 升到 357 KB/s（约 28 倍）。
· 下载按钮改成多线程分片取（8 段并发、真实进度、下完自动比对 SHA-256）：实测再快约 3 倍，约 1 MB/s，115 MB 的包两分钟上下。浏览器若不支持（或你在网址后加 ?native 打开本页），会自动退回浏览器原生下载，不会卡住。

还能再快些：
· 换个时段：白天的跨境链路通常比晚上好不少。
· 复制下载链接（上面那个按钮）拿到直链，丢给 IDM / 迅雷这类多线程工具取。
· 断了不必从头：服务端支持分段下载（HTTP Range），浏览器与下载工具都能续传。

根治办法（需要域名备案）：把安装包放到对象存储 + CDN 上分发，国内用户从就近节点取，通常能到几 MB/s。这条要在阿里云控制台开 OSS / CDN 并给域名做备案接入，属于后续要办的事，办完会写进更新手记。

第 四 卷 · 修 订

更新手记｜最近修订

改了什么都记在册上。这里只列最近三版，历次修订另有专页，不必在本页翻找。

  1. v1.7.2 二〇二六年九月二十三日 修 复
    • 文本档案也有大纲了：Markdown（.md）、纯文本（.txt）与代码档案的阅览栏左侧多了一个「≡ 大纲」。Markdown 的 # 标题会自动分级编号（## 是 1.1，它下面的 ### 是 1.1.1）；代码档案认的是 def / class / function / CREATE TABLE 这类定义行，后面还标着「函数 / 类 / 表」。点一下条目正文就跳过去 —— 在「修订」里写代码时是光标直接落到那一行，接着就能改。档案里没有标题时会给一句"怎么写标题"的引导，不留一片空白。
    • 阅览栏多了「全屏」这一档：原来点「加宽」最多只能到"留着侧栏位置"的宽度，左边永远空出一条；把侧栏收起来之后它居然还按侧栏宽度扣，空出的那一整条其实是白留的。现在按钮是三档循环：默认 → 加宽 → 铺满整窗（侧栏区域也一起用上）。侧栏收起时「加宽」也直接用满可用宽度。
    • 侧栏收起后，左边那段留白还给内容：档案卡片的左内边距从 40px 收到 16px —— 收起侧栏本来就是"我要更多地方看文件"，结果内容还缩着一截（顶栏那点不动，左上角浮着展开把手）。
    • 错题本的题目框自己能滚了：题目很长时不再把整页撑开、把「一键复习」那排按钮顶到屏幕外面 —— 题目框自己滚，卡片标题与按钮始终留在视野里；滚轮也给错题本详情区与复习弹窗挂了兜底。
    • 修掉连接列表"凭空消失"：连上数据库后连接列表会自动收起（把宽度让给编辑区），可它的展开入口长在工作区工具条上 —— 一断开连接、工作区隐藏，入口跟着没了，列表又被收起状态藏着，于是整个界面里再也找不到连接列表、也连不上别的库。现在未连接时列表一律放出来（断开之后你正要挑下一个连接嘛）。
  2. v1.7.1 二〇二六年九月二十三日 新增
    • 笔记本有了 Jupyter 那一套快捷键：先点一下格子的空白处（或按 Esc 从输入框退出来），就进了「命令态」—— a 在上方插一格、b 在下方插一格、dd 删掉这一格、x 剪切、c 复制、v 粘到选中格的正下方、z 撤销单元格操作（剪掉的、删掉的、粘出来的都能退回来）；Enter 回到输入框，m / y 在标题格与代码格之间来回切。在输入框里打字时这些字母就只是字母，不会凭空插出一格。工具条上也放了一个「⌨ 快捷键」，随时点开照单子按。
    • 每个格子前面那道竖杠会表达状态了：蓝色 = 选中了这一格（现在按字母是在操作格子），绿色 = 光标就在这一格里（正在打字）。一屏里只有一格会变色，扫一眼就知道现在按字母是插格还是打字。
    • 补全改成按 Tab 唤起：以前敲一个字就往外冒候选框，连着写代码被一个接一个地打断；现在打字时安安静静，想补的时候按一下 Tab 才弹出来。只有唯一候选时（比如 retu）按一下就直接补成 return；没有候选可补时 Tab 仍然是缩进 —— 写代码按 Tab 缩进的老习惯一点没变。Ctrl+空格 也还能随时唤起。数据库「SQL 查询」页保持原来的敲字即弹（那里补的是库名表名列名，随手就有用）。
  3. v1.7.0 二〇二六年九月二十三日 新增
    • 软件能直接当笔记本用了（.ipynb）：Jupyter 的笔记本档案现在打开就是笔记本 —— 一格一格地写、单独运行某一格、格子之间共享变量、输出与插图都留在格子里。
    • 笔记本的侧边大纲：像 Jupyter 的目录那样自动编号（## 变成 0.1，它下面的 ### 是 0.1.1），只列标题不塞代码，可折叠、点一下跳过去，滚到哪一节就高亮哪一节。
    • 笔记本里也有上色、补全与中文报错：关键字、字符串、数字各自颜色；补全沿用"导包后的成员也能补"那一套；出错给的是中文解释（第几行、什么毛病、怎么改），不是一坨英文 traceback。
    • 错题本里的 SQL 题能在指定的库里重做了：复习弹窗多了一行「在哪运行」（选连接 + 选库），点「运行作答」真的在那个数据库里执行，结果按表格回来，摘要写清「在 哪个连接 / 哪个库 中执行」；没选连接时会明说"这次只做了语法初检"，不让你以为已经跑过了。选过的连接记在这道题上，下次重做直接选中。
    • 每份代码档案有了固定的工作目录：以前运行是在一个临时目录里跑、跑完就把目录删掉 —— 脚本存下的 result.csv 你再也找不到；而库里的档案在磁盘上是哈希名，一眼认不出谁是谁。现在每份代码档案有一个以档案名命名的工作目录：源码（原名）、你放进去给它读的数据文件、它生成的结果都在这里，跑完不删。open("data.txt") 这种相对路径也终于能用了；终端装的包与「运行」在同一个目录，脚本直接就能 import。
    • 运行结果里直接告诉你产物在哪：跑完在输出区上方给出工作目录的完整路径，附「打开工作目录」「定位源码」，并列出这次生成了哪几个文件（这些文件照旧自动入档，库里也看得见）。
    • 字号旁边多了「📁 文件夹」：只有编程类档案才出现，一点就在资源管理器里打开这份代码的工作目录 —— 找它读写的文件不用再翻目录。
    • 补全不再是"写死的词表"：以前只认内置那几百个名字 —— import pandas as pd 之后敲 pd. 什么都没有。现在会问真实的 Python 环境（真 dir()）：导包后的成员、import 行该写哪个模块、from x import … 有哪些名字都给；新装的包立刻生效（结论缓存十分钟，打字不卡手）。
    • 修掉三个"点了没反应"：① 「知识点」小窗其实每次都打开了，但被阅览栏盖在下面（从 v1.6.1 就有的老毛病）；② 笔记本里内容多的格子显示不全（被上色层裁掉，只显示两行高）；③ 打开文件夹 / 定位文件失败时一声不吭，现在会明确告诉你原因。
