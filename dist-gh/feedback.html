写之前，可能省一步

  • 先看「更新手记」：不少毛病是最近几版刚修掉的，网页上的手记按版本列得很细。
  • 版本号在软件里：设置 → 关于 能看出版本、构建编号与完整性校验结果 —— 报问题时带上版本号，定位会快很多。
  • 浏览器下载提示「有风险」是正常的：安装包没有代码签名证书，Chrome / Edge 与 Windows 一律会提示。可在官网下载区按 SHA-256 自行核对，或在软件 设置 → 关于 里对同一组校验码。
  • 下载慢：服务器在境外，跨境链路高峰时段会明显变慢。可用浏览器或下载工具断点续传（服务端支持 Range 分段），换个时段再试通常更快。

反馈会怎么处理

  • 进到后台清单，按「待处理 / 已处理」标记。
  • 修好之后会写进更新手记，注明是哪个版本改的。
  • 留了邮箱的，若有需要会回信；不留也能收到处理，只是没法回你。
