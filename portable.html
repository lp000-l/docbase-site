免安装、自带编程环境、资料存在自己旁边 —— 拷进 U 盘或移动硬盘，
插到任何一台 Windows 电脑上，双击就能用；换台机器插上，接着上次的活干。

它解决什么问题

别人的电脑上没有你的环境，便携版把这套环境一起带上

安装版把程序装进系统、资料放在你指定的目录（本机 D:\does 那种）；便携版则是"一整个文件夹就是一个完整的聚文坞" —— 程序、Python 运行环境、你的全部资料都在这个文件夹里，一句"拷过去"就完事。 它不改注册表、不装到「添加或删除程序」里，也不往 C 盘用户目录里写东西（这一点在别人的电脑、机房的电脑上尤其要紧）。

NO. 01

免安装，双击即用

文件夹拷到哪儿、盘符变成什么，都不影响。没有安装程序、没有卸载残留，不想要了直接删掉整个文件夹 —— 包括你放进去的资料，一起带走。

便携版更容易被误报一次：它里面有一个完整的 python.exe，某些杀软对"U 盘里的绿色版 Python"比较敏感。若不放心，可只保留安装版；或把整个文件夹加入白名单。

三步用起来

怎么用

没有安装步骤，只有"拷贝"和"双击"。

  1. 解压到 U 盘（或任意文件夹、移动硬盘）

    把 FileDock-Portable-1.7.7.zip 解压，得到一个名为 聚文坞便携版 的文件夹。整个文件夹拷到 U 盘根目录就行 —— 别只拷里面的 exe，程序与资料都在文件夹里。

  2. 双击文件夹里的「聚文坞.exe」

    就这么简单，没有安装向导、不用管理员权限。第一次启动会稍慢几秒（U 盘读取比硬盘慢），之后正常。

    程序会认出自己旁边有 portable.txt，于是自动进入便携模式：资料存在自己旁边的 data 目录，不写进 C 盘的 AppData。

  3. 正常用；要换电脑时，退出程序、拔盘、插到新机器上再双击

    新电脑上盘符可能从 D: 变成 E:——没关系，程序里所有路径都是相对自己算出来的。档案、知识点、错题、数据库连接、代码工作目录全都在 data 里，接着上次的活干。

    拔盘之前先退出程序，别在写资料的时候直接拔。

想备份？把整个文件夹拷走即可。想换台机器继续？同上。想彻底不留痕迹？删掉整个文件夹 —— 它不往系统里写任何东西。

自带的编程环境

插到"裸机"上也能跑代码

便携版里塞了一份 Python 3.13。打开「环境」面板，解释器一行会显示「便携」—— 意思是"用的是随盘自带的那个"。下面这些开箱就有：

  • 数据三件套：numpy、pandas 2.3、matplotlib —— 读数据、算表格、画图都能直接来。matplotlib 已配好 中文字体，标题写中文不会变成方框。
  • Excel 读写：openpyxl —— 让脚本生成 / 修改 .xlsx，中文表头与内容都不出错。
  • 联网取数：requests —— 抓网页接口、下载文件。
  • 还能自己装包：代码档案的「⌨ 终端」里可以直接 pip install（包会装到这份档案自己的工作目录，跟着盘走），装完脚本里直接 import。
  • 要用自己电脑上的 Python：设置 → 解释器里填你自己的路径（比如装了 Anaconda）；留空就用自带的。注意设置里存的是绝对路径，换台电脑就失效 —— 那时会自动落回自带的那个，不会打不开。
怎么选

便携版与安装版，区别在哪

两个版本功能完全一样，是同一份代码打出来的；区别只在"装在哪、资料放哪、怎么更新"。

安装版（推荐日常用）便携版（U 盘随身）
安装运行安装程序，装进系统免安装，解压即用
编程环境用你电脑上的 Python / Node（没装就自己装一份）自带 Python 3.13 + 常用库，裸机可用
资料位置你指定的目录（首次启动可选）就在程序旁边的 data/
换电脑拷资料目录，或重新安装整个文件夹拷过去，插上就用
自动更新有（打开软件提示新版本）没有 —— 升级就换一份新的便携包（资料不受影响）
系统残留有安装记录，卸载可清零残留，删文件夹即可
启动速度硬盘/SSD，最快U 盘慢些，首次启动多等几秒
包体积约 114 MB约 212 MB（压缩包）/ 537 MB（解压后）

日常自己电脑上用，还是建议下载安装版（有自动更新、启动更快）；便携版适合机房、别人的电脑、多台机器之间来回跑、以及"不想在系统里留东西"的场合。

用之前先知道这几条

注意事项

  • 盘符会变，这是正常的。同一支 U 盘在这台电脑是 E:、换一台可能是 F:。程序里所有路径都相对自己算，不会因此打不开；但你在系统里给别的软件指路径时要留意。
  • 别在程序运行时拔盘。写资料写到一半拔掉可能损坏数据（和任何软件一样）。先退出程序，等 U 盘的指示灯不闪了再拔。
  • U 盘比硬盘慢。第一次启动、第一次跑 pandas、第一次打开大表格都会慢几秒到十几秒；之后正常。若常年在固定电脑上用，把文件夹放在硬盘上会更舒服。
  • 便携版不参与自动更新。要升级就下载新的便携包，把它解压到新文件夹，再把旧文件夹里的 data 拷过去覆盖即可 —— 资料一条不丢。也可以先备份整个旧文件夹再替换。
  • 不要删 portable.txt。它是"我在便携模式"的标记；删掉后程序会退回安装版行为（把资料写进 C 盘的用户目录）。同理，不要只考 exe 出来单独运行。
  • U 盘写保护 / 只读介质下程序能打开，但存不了资料 —— 那种介质请改用安装版。
常 见 问 题

可能你还想问

便携版和安装版能同时装吗？资料会串吗？

能同时存在，资料各自独立、不会串：安装版的资料在你指定的目录，便携版的资料在它自己的 data 里。想搬资料，把其中一个的 data 目录整体拷到另一个上覆盖即可。

能不能把资料放到 U 盘之外（比如电脑硬盘上的某个目录）？

便携版的设计就是"资料在程序旁边"，这样插到哪台机器都是一套完整的东西。如果想让程序在 U 盘、资料在硬盘，可以用安装版并把资料目录指到硬盘上；或者反过来，把便携文件夹整个放在硬盘上、用 U 盘做备份（把整个文件夹拷回 U 盘即可）。

插到没有 Python 的电脑上，数据库工作台能用吗？

能。SQLite 是程序内置的，直接可用；连 MySQL / PostgreSQL / SQL Server 只要求网络通，不要求那台电脑装数据库客户端。

宏病毒 / 学校机房的安全策略会不会拦它？

聚文坞不写注册表、不装驱动、不请求管理员权限，通常不需要特殊放行。若机房的策略禁止运行 U 盘程序（不少单位会这么设），那就没法绕开 —— 那属于策略限制，不是软件的问题。这种情况下可以先在允许的机器上把资料整理好，或改用安装版。

升级便携版，我的资料会不会丢？

不会。步骤是：① 下载新的便携包并解压到新文件夹；② 把旧文件夹里的 data 整个拷进新文件夹覆盖；③ 确认新的能打开、资料都在，再删旧的。先别删旧的，确认无误再删。
